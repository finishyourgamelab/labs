# 自訂關卡目錄

在此放置編輯器儲存的 `.lua` 關卡檔。遊戲啟動時會**優先載入**此目錄內所有 `.lua`（依檔名排序）；若目錄為空則使用內建關卡。

## 啟動編輯器

```bash
cd prototypes/rockman-love2d
./run_editor.sh
# 或
love . editor
```

## 啟動遊戲（載入自訂關卡）

```bash
love .
```

## 關卡檔格式

由編輯器自動產生，範例：

```lua
return {
  id = 1,
  title = "我的關卡",
  boss_kind = "lightning_sect",
  weapon_drop = "thunder_palm",
  arena = { ... },
  map = [[
############################################################
#..........................................................#
...
]],
}
```

## 圖層符號

| 符號 | 說明 |
|------|------|
| `#` | 山石 |
| `=` | 木道（僅頂部可踩） |
| `.` | 空氣 |
| `^` | 竹刺 |
| `P` | 玩家出生 |
| `@` | 惡徒 |
| `E` | 決鬥圈入口 |
| `a` | 圈內落點 |
| `B` | 掌門 |
| `G` | 圈門（打倒後開啟） |
| `e` | 圈出口（回江湖） |
| `F` | 關卡出口 |
| `M` | 吊橋 |
| `Q/R/K/N/%` | 收集物 |
