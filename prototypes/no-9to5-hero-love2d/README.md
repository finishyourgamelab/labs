# No 9-to-5 Hero - Love2D

一個獨立生成的 Love2D Vampire Survivor 風格原型。玩家在辦公室怪物潮中移動、生存、自動攻擊，拾取 XP 後升級並選擇強化。

## 執行

```sh
love prototypes/no-9to5-hero-love2d
```

或在此資料夾內執行：

```sh
love .
```

## 操作

- `WASD` / 方向鍵：移動
- `1` / `2` / `3`：升級時選擇技能
- `R`：遊戲結束後重新開始
- `Esc`：離開

## 內容

- 自動瞄準最近敵人的射擊
- 隨時間提高壓力的敵人生成
- 一般敵人與菁英敵人
- XP 寶石、等級與三選一升級
- 生命值、分數、存活時間與遊戲結束畫面
